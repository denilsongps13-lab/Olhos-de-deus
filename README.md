# Olhos de Deus

Central experimental para estudar e integrar conceitos de agentes de IA, automação, análise de código, QA e workflows visuais.

## Projetos de referência

1. Graphify-Labs/graphify
2. Comfy-Org/ComfyUI
3. github/spec-kit
4. petrkindlmann/qa-skills
5. ayghri/i-have-adhd
6. msitarzewski/agency-agents
7. google/artemis

## Estrutura

- `sources/` — documentação das fontes e componentes estudados
- `core/` — núcleo futuro do Olhos de Deus
- `agents/` — agentes especializados
- `workflows/` — orquestração e automações
- `skills/` — skills reutilizáveis
- `docs/` — arquitetura e documentação

Os projetos externos permanecem identificados por origem. Código de terceiros só deve ser incorporado conforme sua licença e mantendo atribuições exigidas.
